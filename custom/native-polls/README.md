# Встроенные опросы

Самостоятельный модуль Rocket.Chat 8.9.0 поверх установленного образа шаблонов,
устройств и AI. Существующие приложения опросов не изменяются и не удаляются.

## Использование

Нажмите **◉ Опрос** в панели редактора. Выберите комнату, введите вопрос,
описание и 2–12 вариантов. Доступны один или несколько ответов с ограничением
числа выбранных вариантов, анонимное/открытое голосование, результаты сразу или
после голосования, срок окончания. По умолчанию опрос анонимный, результаты
скрыты до голосования. Вопрос и варианты фиксируются при публикации.

Карточка отображается в переписке. Выбор можно изменить или отозвать, пока
опрос открыт. Проценты рассчитываются от количества участников; при нескольких
ответах их сумма может превышать 100%. В открытом режиме кнопка «Кто выбрал»
показывает участников по 25 записей. Автор и администратор могут завершить
опрос досрочно. После завершения результаты видны всем участникам комнаты.

Ссылка `/polls/ID` открывает отдельную страницу с теми же правами. Карточки
обновляются каждые 15 секунд только в видимой части активной вкладки, не сбрасывая
незавершённый выбор. Создание поддерживает обычный и rich-text редактор;
публикация не меняет текст существующего черновика.

## Архитектура и права

- Сервер использует штатные авторизацию, проверку комнаты и отправку сообщения.
  Поддержаны обычные каналы, закрытые группы и личные чаты. Зашифрованные комнаты
  и Omnichannel исключены. Опросы публикуются в основной поток комнаты.
- Уникальный индекс `(pollId, userId)` исключает повторные бюллетени. Изменение
  голоса выполняется в транзакции MongoDB с изменением revision опроса; закрытие
  конкурирует за ту же запись. Требуется replica set, как на локальном стенде.
- Анонимный режим не возвращает личности проголосовавших ни автору, ни другим
  участникам. В базе идентификатор пользователя хранится для защиты от повторных
  голосов: это анонимность интерфейса/API, не криптографическая анонимность.
- Удалённое/изменённое сообщение и утрата членства закрывают доступ. Только
  владелец или администратор с доступом к комнате может закрыть опрос.
- Собственные коллекции: `rocketchat_native_polls`, `rocketchat_native_poll_ballots`.
  Опросы не имеют автоматического TTL; архивирование и экспорт пока не добавлены.
  Нативные мобильные клиенты видят обычное сообщение со ссылкой на веб-страницу.

## Сборка и проверки

```sh
node --test custom/native-polls/test/*.test.cjs
DOCKER_BUILDKIT=0 ./deploy/local/manage.sh build-polls
POLLS_TEST_BASE=http://localhost:3001 node custom/native-polls/test/live.cjs
POLLS_TEST_BASE=http://localhost:3001 node custom/native-polls/test/browser.cjs
node custom/native-polls/test/cleanup.cjs
```

Итоговый образ: `rocketchat-local:8.9.0-polls-v1`; базовый образ:
`rocketchat-local:8.9.0-canned-v1`. Запускайте тестовую копию на 3001 во внутренней
сети Compose с прежними `MONGO_URL` и `TRANSPORTER`, задав `ROOT_URL` тестового
порта. Живые тесты используют отдельные временные группы и удаляют их. ID
созданных тестовых опросов сохраняются в приватной `.state` для точечной очистки.

Перед внедрением проверьте итоговый образ на 3001, остановите тестовую копию
и основное приложение, выполните `manage.sh backup` и `gzip -t`. Сохраните прежний
ID образа, укажите новый в приватном `.env`, выполните `manage.sh start` и повторите
проверки на 3000. Для отката верните прежний ID и выполните `manage.sh start`.
Подробные результаты: [VALIDATION.md](VALIDATION.md).
