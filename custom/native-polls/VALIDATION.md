## Реальные MongoDB и API

На итоговом образе на 3001, затем на основном сервере на 3000 проверены:

- Отказ без входа и для неучастника закрытой группы, включая администратора.
- Запрет подмены пользователя в бюллетене, анонимность ответов API и запрет
  получения имён в анонимном режиме.
- Скрытые результаты до голосования, изменение и отзыв выбора; после отзыва
  скрытые результаты вновь недоступны.
- Два параллельных изменения голоса одного пользователя: один бюллетень,
  корректные итоговые суммы. Голосование и закрытие одновременно: транзакции
  согласованы, после завершения новые изменения отклоняются.
- Множественный выбор, число участников и голоса по каждому варианту,
  получение имён в открытом режиме.
- Автоматическое завершение по сроку, запрет закрытия чужого опроса обычным
  пользователем, отказ после удаления исходного сообщения и исключения из группы.

голосование, восстановление выбора после перезагрузки, изменение и отзыв голоса,
скрытые результаты и закрытие автором. Кнопка создания работает в обычном и
rich-text редакторе. Проверены ограничение выбора, список участников открытого
опроса, отдельная страница, ширина 390 px, тёмная цветовая схема и очистка при

Найдены и исправлены выбор левого контейнера аватара вместо основного контейнера
сообщения, стабильные доступные имена вариантов после появления процентов,
поддержка rich-text редактора и восстановление карточки при гонке публикации.
