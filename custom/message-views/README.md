# Подтверждения просмотра — тестовый этап

Самостоятельный модуль для Rocket.Chat 8.9.0. Получатель явно подтверждает
просмотр текущего текста; автор видит имена и серверное время. Изменения текста
требуют нового подтверждения. Срок хранения — 90 дней, уникальный и TTL индексы.

Разработан и проверен на порту 3001: 8 автономных тестов, два браузера,
закрытая группа, изоляция прав, отзыв членства, смена аккаунта, мобильный диалог,
буквальное отображение текста. 50 повторов сохраняют одну запись: p50 18 мс,
p95 21 мс на локальном стенде. Это небольшой последовательный тест, не оценка
производительности большой установки.

**На основном сервере не установлен:** пользователь перенаправил работу на
качественный модуль опросов. Тестовый контейнер остановлен и удалён.

Проверки: `node --test custom/message-views/test/*.test.cjs`;
`VIEWS_TEST_BASE=http://localhost:3001 node custom/message-views/test/live.cjs`.
Сборка: `DOCKER_BUILDKIT=0 ./deploy/local/manage.sh build-views`.

Штатные Enterprise-проверки не меняются. Поддерживаются только доступные участнику
незашифрованные текстовые сообщения обычных комнат. Данные подтверждений тестов
хранятся в собственной коллекции с TTL; тестовые группы удалены.
